# 🐾 Pet Adoption Portal

A full-stack web application designed to connect users with pets available for adoption. Users can browse available pets, view pet details, register, and submit adoption requests. An admin dashboard allows administrators to manage pets and adoption requests.

## ✨ Features

### 👤 User Features

* User registration and login
* Browse available pets
* View pet details
* Submit adoption requests
* View user profile

### 🛠️ Admin Features

* Admin login
* Add and manage pets
* View and manage adoption requests
* Update pet availability
* Upload pet images

## 🛠️ Technologies Used

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Backend:** Java, Spring Boot, REST APIs
* **Databases:** MySQL, MongoDB
* **Tools:** VS Code, Git, GitHub, Postman, Maven

```text

  ↓

  ↓

```

## 🚀 How to Run

### Backend

1. Open the backend project.
2. Make sure Java and Maven are installed.
3. Configure your local databases.
4. Run the Spring Boot application.

Backend:

```text
http://localhost:8080
```

### Frontend

Open the terminal inside the React project folder:

```bash
npm install
npm start
```

Frontend:

```text
http://localhost:3000
```
